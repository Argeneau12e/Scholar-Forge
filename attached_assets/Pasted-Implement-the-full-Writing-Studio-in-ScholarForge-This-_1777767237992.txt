===============================================================
PART B: CITATION INSERTION SYSTEM
===============================================================

Extend the Tiptap editor with a custom @mention extension for citations.

When user types @ in the editor:
1. A floating citation picker appears (320px wide, appears above 
   the cursor position)
2. The picker has a search input — searching queries BOTH:
   a. The user's saved collection (instant, no API call)
   b. OpenAlex live search (debounced 500ms, shows "Searching..." 
      while loading)
3. Results shown as a list with paper title, authors, year, 
   and source badge (Collection / OpenAlex)
4. Keyboard navigable (arrow keys to select, Enter to insert)
5. On selection:
   - Insert inline citation node in the editor
   - Citation node renders as a non-editable chip:
     "(Dawson et al., 2022)" for author-date styles
     "[14]" for numbered styles (Vancouver)
   - Citation chip is clickable → shows full reference card in right panel
   - Citation chip has a × button to remove (with undo toast)
   - If paper not already in collection, automatically add it
   - Bibliography in right panel updates immediately

Citation node data model (Tiptap custom node):
{
  type: 'citation',
  attrs: {
    citationKey: string,
    paperId: string,
    inlineText: string,
    doi: string
  }
}

Citation rendering:
For author-date styles (APA, Harvard, Chicago):
"(First Author et al., Year)" for 3+ authors
"(Author & Author, Year)" for 2 authors  
"(Author, Year)" for 1 author
For numbered styles (Vancouver, MLA):
"[N]" where N is the order of first appearance in the document

When a citation is removed from the text:
- Remove from bibliography (with 5-second undo toast)
- Renumber all subsequent citations for numbered styles

===============================================================
PART C: AUTO-BIBLIOGRAPHY
===============================================================

Create /client/src/components/editor/BibliographyPanel.jsx

This lives in the right panel of the Writing Studio.

REAL-TIME BEHAVIOUR:
- Listens to Tiptap editor content changes
- Extracts all citation nodes from the document
- For author-date styles: sorts alphabetically by first author surname
- For numbered styles (Vancouver): sorts by order of first appearance 
  in text
- Formats each using the existing Citation.js engine
- Renders the formatted list in the panel

DISPLAY:
- Each bibliography entry as a line item with:
  - Line number (for Vancouver)
  - Formatted citation text
  - Small icons: copy (copies this citation), open DOI, remove
- "Copy all" button: copies entire bibliography as plain text
- "Export bibliography" button: opens existing export modal 
  pre-populated with this document's references
- Style indicator at top: "Vancouver format · 14 references"
- Warning if any reference is missing required fields 
  (e.g. missing year): amber highlight on that entry with 
  "Incomplete — verify manually" tooltip

CONFLICT DETECTION:
If the same paper is cited twice with slightly different metadata 
(e.g. once from collection, once from OpenAlex with different 
author list), show a merge warning:
"Two entries for [Title]. Which is correct?"
Allow user to select the correct one — merges all citations to 
use the selected metadata.

===============================================================
PART D: INLINE AI ASSISTANCE
===============================================================

When user selects any text in the editor, show a floating 
action bar with these options:

"Improve ✦" → POST /api/coach with selection, returns rewrite
"Cite ✦" → searches for papers supporting the selected claim
"Simplify ✦" → returns plain English version of selection
"Academic ✦" → makes language more formally academic
"Expand ✦" → adds 2-3 sentences developing the point
"Hedge ✦" → adds appropriate academic qualification language

Each action:
1. Shows loading state inline ("Improving...")
2. Returns suggestion in a diff view — original crossed out, 
   new version shown in --sf-mint
3. "Accept" button replaces selection with suggestion
4. "Reject" button restores original
5. Rejected suggestions logged so the same suggestion isn't 
   offered again

COMMAND PALETTE (Cmd+K or Ctrl+K anywhere in editor):
Opens a searchable command menu with all AI actions plus:
- "Set writing goal for today" → updates daily word target
- "Check originality of this paragraph" → sends selection to 
  plagiarism checker
- "Find papers for this section" → runs a search based on 
  the surrounding paragraph context
- "Insert subheading" → suggests appropriate H2/H3 text based 
  on surrounding content
- "Summarise what I've written so far" → Claude reads entire 
  document and returns a 3-sentence summary

===============================================================
PART E: DISTRACTION-FREE MODE
===============================================================

Toggle with F11 or the ⤢ button in the toolbar.

Hides: navigation, both panels, toolbar, status bar
Shows: only the white writing surface, centered, 700px max-width
Floating word count: bottom center, very small, --sf-text-3 color
Daily goal: a thin colored line at the very bottom of viewport,
  grows right as words are written (green when goal hit)
Exit: press Escape or move mouse to very top of screen (reveals 
  a minimal exit button)

===============================================================
PART F: VERSION HISTORY
===============================================================

Auto-snapshot system:
- Every 30 minutes while the document has unsaved changes, save 
  a snapshot to sf2_documents[id].snapshots
- Keep maximum 20 snapshots (FIFO — oldest removed when 21st added)
- Manual snapshot: "Save version" button in right panel

Version history panel (right panel tab):
- Timeline of snapshots (newest first)
- Each shows: timestamp, word count at that point, 
  "words added" since previous snapshot
- Click snapshot: shows a preview panel with the document content 
  at that point (read-only)
- "Restore this version" button: replaces current content after 
  confirmation dialog ("This will replace your current draft. 
  Your current version will be saved first.")
