2. ERROR HANDLING AUDIT:

- Search fails: show "Search unavailable. Paste your snippet manually." 
  with the paste textarea auto-opened
- PubMed timeout (>8 seconds): show "PubMed is slow right now. 
  Trying Semantic Scholar..." and fall back automatically
- Claude API fails: show "AI unavailable. Try again in a moment." 
  with a retry button — never a blank screen
- Export fails: show "Export failed. Copy your bibliography below:" 
  and show plain text version inline
- Empty collection: show illustrated empty state with text 
  "Your collection is empty. Search for a topic to get started."
